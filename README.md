## AI를 다루는 방식

한 번 내린 판단은 스킬과 컨텍스트로 고정해 AI가 반복 복제하게 만들고, 같은 결정을 두 번 하지 않습니다.

AI가 만든 코드는 lint·테스트코드·hook처럼 더 저렴한 비용으로 막아 사람이 리뷰할 양을 줄이고, 리뷰에서 나온 지적은 회고를 통해 컨벤션·스킬에 녹여 다음엔 자동으로 걸리게 합니다.

> [AI에게 잘 시키고, 잘 리뷰합니다](docs/vision/ai-delegation-and-review.md)
